1. Почему папку venv не нужно коммитить в Git?
Она занимает слишком много места и привязана к конкретной операционной
системе и версии Python — на другом компьютере она всё равно не заработает,
а библиотеки проще скачать заново.
3. Что произойдёт, если другой разработчик склонирует репозиторий без папки venv? Как ему восстановить окружение?
Он получит только код без установленных библиотек (проект не запустится).
Чтобы восстановить окружение, ему нужно создать свой venv (python3 -m venv venv),
активировать его и установить зависимости командой pip install -r requirements.txt.
5. Зачем нужен файл requirements.txt и как он связан с .gitignore?
requirements.txt хранит список всех библиотек проекта для быстрой установки
окружения на другом ПК. В отличие от папки venv (которую скрывают через .gitignore),
этот файл не игнорируется и обязательно загружается в Git.
